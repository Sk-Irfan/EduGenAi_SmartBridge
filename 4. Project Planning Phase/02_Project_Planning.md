# EduGenie Project Planning

## Project Timeline

| Week | Phase | Activities | Deliverable |
|---|---|---|---|
| Week 1 | Setup and Ideation | Install tools, create repository, define problem | Project setup |
| Week 2 | Requirement Analysis | User stories, requirements, technology stack | Requirement documents |
| Week 3 | Project Design | Architecture and proposed solution | Design documents |
| Week 4 | Backend Development | FastAPI setup and health endpoint | Working backend |
| Week 5 | Gemini Integration | Connect Gemini and create prompts | AI service |
| Week 6 | Core Features | Ask, explain, quiz, summarize, roadmap | API features |
| Week 7 | Frontend Development | HTML, CSS, and JavaScript interface | Working web UI |
| Week 8 | Testing | Functional, performance, and UAT testing | Test reports |
| Week 9 | Documentation | Final report and functional specification | Project documentation |
| Week 10 | Demonstration | Screenshots, presentation, and future plan | Final demonstration |

## Project Milestones

### Milestone 1: Environment Setup

- Python installed
- Git configured
- GitHub repository created
- VS Code project opened

### Milestone 2: Backend Foundation

- FastAPI starts successfully
- Health endpoint works
- Swagger documentation is available

### Milestone 3: AI Integration

- Gemini API key configured
- Gemini connection tested
- AI service created

### Milestone 4: Core Features

- Question answering completed
- Concept explanation completed
- Quiz generation completed
- Text summarization completed
- Roadmap generation completed

### Milestone 5: Frontend

- Homepage created
- Feature cards created
- API requests connected
- Responsive design completed

### Milestone 6: Testing

- API tests completed
- Invalid input tested
- Performance measured
- UAT completed

### Milestone 7: Final Submission

- README updated
- Reports exported to PDF
- Screenshots captured
- GitHub repository updated
- Demonstration prepared
