# EduGenie Customer Journey Map

## Target User

Students, self-learners, and educators.

## Customer Journey

| Stage | User Action | User Problem | EduGenie Solution |
|---|---|---|---|
| Discover | User opens EduGenie | User does not know where to begin | Simple feature cards |
| Ask | User submits a question | Online answers may be confusing | Direct AI answer |
| Understand | User requests an explanation | Concept may be difficult | Level-based explanation |
| Practice | User generates a quiz | User may not have practice material | Topic-specific quiz |
| Review | User pastes study material | Material may be lengthy | AI summary and key points |
| Plan | User requests a roadmap | User does not know what to learn next | Personalized learning path |
| Improve | User repeats practice | User wants better understanding | Follow-up questions and examples |

## User Expectations

- Simple and accurate answers
- Fast response
- Beginner-friendly explanations
- Useful examples
- Easy quiz generation
- Structured learning roadmap
- Responsive interface

## Main Pain Points

- Difficult educational language
- Large amounts of study material
- Lack of personalized guidance
- Limited practice questions
- Confusing learning sequences

## Opportunities

EduGenie can improve the learning experience by combining explanation, practice, summarization, and roadmap creation in one application.
