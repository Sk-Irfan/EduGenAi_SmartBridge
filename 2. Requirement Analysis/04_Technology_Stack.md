| Backend Framework | FastAPI | REST API development |
| AI Platform | Google Gemini | Educational content generation |

| Frontend Structure | HTML | Web page structure |
| Frontend Styling | CSS | Layout and responsive design |
| Frontend Logic | JavaScript | Calling backend APIs |
| Validation | Pydantic | Request validation |
| Configuration | python-dotenv | Loading environment variables |
| Testing | Pytest | Automated testing |
| Version Control | Git | Source code management |
| Code Hosting | GitHub | Project hosting |
| Documentation | Markdown and PDF | Project reports |
| Optional Deployment | Docker | Application packaging |
